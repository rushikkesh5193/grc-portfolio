## 1. Purpose
To define acceptable use of ExampleOrg-issued equipment, systems, and information assets by
employees and contractors.

## 2. Scope
Applies to all corporate-issued laptops, mobile devices, email, cloud accounts, and any
personal device used to access ExampleOrg systems.

## 3. Policy Statements

### 3.1 General use
- Corporate systems and devices are provided for business purposes; incidental personal
  use is permitted provided it does not interfere with duties, consume excessive resources,
  or violate any other ExampleOrg policy.
- Users must not attempt to disable, bypass, or circumvent security controls (EDR, MFA,
  web filtering) on any corporate device.

### 3.2 Endpoint security
- All corporate laptops must run the company-managed EDR agent and remain on a supported,
  patched operating system version at all times.
- Devices must be locked (screen-lock) when unattended, and disk encryption is mandatory
  on all endpoints handling customer or corporate data.

### 3.3 Data handling
- Customer PII and KYC data must never be downloaded to personal (non-corporate) devices
  or stored on unauthorized cloud services (personal Google Drive, Dropbox, etc.).
- Data must be classified and labelled per the Information Classification standard before
  transfer outside ExampleOrg systems.

### 3.4 Email and internet use
- Corporate email must not be used to send unencrypted customer PII externally.
- Users must not click links or open attachments from unverified senders; suspected
  phishing must be reported per the Incident Response Policy within the same business day.

### 3.5 Remote working
- Remote access to production systems requires VPN or zero-trust network access with MFA.
- Public Wi-Fi use for accessing production systems is prohibited without VPN.

### 3.6 Prohibited activities
- Installing unauthorized/unapproved software on corporate devices
- Sharing login credentials with any other individual, including colleagues
- Using corporate systems to engage in illegal activity or harassment
- Connecting personal USB storage devices to systems handling customer PII

## 4. Enforcement
Violations are handled per the disciplinary process referenced in the Information
Security Policy.
